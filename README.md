# Social Wars Asset Explorer

**[Abrir el explorador](https://dasort.github.io/social-wars-asset-explorer/)**

Un lugar para volver a ver las unidades, edificios y otros recursos de Social Wars desde el navegador.

Podés buscar por nombre o número, ver las unidades quietas, andando o atacando y recorrer los sprites y sus fotogramas. Las previews de las 403 unidades se seleccionaron y revisaron manualmente para mostrar cada acción.

El catálogo contiene **862 recursos** y **419.371 fotogramas inventariados**. Además de unidades, incluye edificios, recursos, colecciones, terreno y otros elementos del juego.

## Cómo usarlo

- Usá la búsqueda y las categorías para encontrar un recurso.
- Elegí una vista estática o una animación en el catálogo. Por defecto se muestra **Andando**.
- Abrí una tarjeta para ver sus sprites y recorrer los fotogramas de cada grupo.
- Las imágenes se cargan a medida que las necesitás. La ruedita indica que todavía faltan imágenes; lo que ya llegó sigue visible.

Desde la ficha también podés descargar el frame mostrado como PNG o el SWF original dentro de un ZIP. Las imágenes de la web están optimizadas a 220 px; el SWF conserva el recurso de origen.

## De dónde salen los recursos

El material de partida es la versión **0.02a de [Social Warriors](https://github.com/AcidCaos/socialwarriors)**, de AcidCaos. A partir de esos archivos se extrajeron los fotogramas y se preparó este explorador.

**Social Wars es un juego de Social Point.** Este es un proyecto no oficial. Los recursos originales pertenecen a sus respectivos titulares; este repositorio no pretende atribuirse su autoría ni conceder permisos sobre ellos.

El trabajo de este proyecto es el explorador, la preparación de las imágenes y la selección de las previews.

## Sobre el repositorio

La rama `sw-pages-6614d195a7c4` contiene el sitio que está publicado. Los paquetes de imágenes están en `sw-assets-6614d195a7c4` y se descargan cuando hacen falta.

Las otras ramas conservan pruebas y pilotos del desarrollo. Para usar el explorador no hace falta descargar el repositorio ni instalar nada: **[abrilo acá](https://dasort.github.io/social-wars-asset-explorer/)**.
